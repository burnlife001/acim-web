## 核心框架与心智模型

### 总纲
**凡是真实的, 不受任何威胁; 凡是不真实的, 根本不存在。上主的平安即在其中。**
课程不是教爱(爱无法传授), 而是清除爱的障碍。与爱相对的是恐惧——但实相没有对立。

### 两个思想体系(根本二分)
- **小我 (ego)**: 基于分裂假设的解释器。产物 = 罪咎、恐惧、特殊性、死亡。它不可改良, 只能弃用(undo)。
- **圣灵 (Holy Spirit)**: 上主与分裂心灵间仅余的交流管道; 兼具真知与知见能力的"伟大修正原则"。祂不改变梦的内容, 只改变你对梦的诠释。
- 每时每刻你只在二者间选顾问。**平安是唯一的试金石**: 不安 = 选错了顾问。

### 奇迹 (Miracle)
- 奇迹 = 知见的转变(由恐惧切到爱), 不是外在事件。**无难易之分**——所有问题是同一个错误。
- 奇迹是施受双赢: 疗愈的给予者同时被疗愈("推恩": 给即是得)。
- 用来证明特殊性(炫耀、传教)即已误用。→ ch01(50条奇迹原则)

### 宽恕 (Forgiveness)——全书唯一的通用修正
- 宽恕不是纵容行为, 而是**撤销对错误诠释的信仰**: 收回投射 → 交出评判 → 邀请圣灵 → 认出对方清白无罪。
- 宽恕属于幻相领域, 但它是"以圣灵目的为目的"的幻相, 是由世界通向天堂唯一的桥。
- **零例外原则**: 一个例外即全盘失效; 例外感标记出最需要练习的位置。→ ch09, ch17, ch22, ch45

### 投射与知见 (Projection makes Perception)
- 你看到的世界是内心信念的投射; **果冒充因**是小我的核心骗局(先定罪于内, 再"发现"罪在外)。
- 修正次序: 认出烦扰源于知见而非外境 → 认领回决定权 → 重选诠释。→ ch21, ch28

### 神圣一刻 (Holy Instant)
- 放下全部过去记忆与未来忧虑, 只愿看见此刻的清白。一次神圣一刻 = 一次小型救赎。
- 靠愿心允许, 不靠努力制造。→ ch15, ch27

### 特殊关系 vs 神圣关系
- 特殊关系 = 用一个人填补匮乏的交易(爱的替代品, 实为恨的避风港, 对过去的报复)。
- 神圣关系 = 同一关系被圣灵重新定向: 目的由"索取"改为"共同觉醒"。**方法: 自问"目的何在"**。→ ch16, ch17, ch22, ch24

### 身体与世界
- 身体不是自我, 是交流工具; 疾病 = 为分裂作证的假见证。疗愈永远是心灵的疗愈。→ ch08, ch10, ch27
- 世界是中性的教具: 你赋予它什么目的, 它就教你什么。

### 操练体系(练习手册)
- 上篇(1–220课): 化解旧知见(清空错误权重); 下篇(221–365课): 活出正知见(直接体验, 文字退位)。
- 总则: 一天一课; 不设例外; 无需相信, 只需运用; 抗拒本身即练习材料。→ ch32, ch41

### 小小的愿心 (Little Willingness)
全课程唯一的前提条件: 不要求信心, 只要求愿意。愿心一粒, 圣灵完成其余。→ ch18

### 教师之道(教师指南)
- 教就是学; 老师与学生互为师生; 以身作则即全部教学。
- 上主之师不完美, 其使命是在反复教人完美之道中自己学会。→ ch42–44

## 场景表达规范
- **牺牲基调世界的表达纪律**: 读者默认以"牺牲/等待/义务"翻译一切含糊表述。涉及痊愈/宽恕/给予/一体等主题时，必须主动写死三点: **不用你等、不用你做、什么是自动发生的**，并写明因果方向（"你先好，他人自动就好"，绝非"你先改变他人才有资格好"）。含糊即默认小我的翻译。宁可啰嗦(max2)，不可留白。
- **拆穿防卫型解法**: 保持好心情、统计安慰（99.9%干净）、距离安全（十万八千里）——凡"攻击真实+躲避成功"结构的解法都要点名：安全感建立在梦的规则上，等于没解。真解永远是"攻击不可能"，不是"攻击打偏了"。
- **读者自带 debug 能力时，导师做质检员**: 不替读者重写他的"反编译"，只指认断点位置（"断点打在事实与评判之间的那个箭头"）、逐环质检（哪环是事实、哪环是评判注入、哪环不可证伪）。读者自己挖到的链条，附着力远超导师代写的。
- **读者版本优先**: 读者的修订更优时直接收为定稿，质检员不护稿。

## 判别器与验证规范
- **判别器优先**: 给读者可自验的一刀切判别器，而非道理清单。核心判别器："它要我维护什么吗？"——需维护/防卫/喂养 = 安装包 = 小我；指向松手/自动发生 = 卸载 = 圣灵。判别教导不看内容，看它走后你身上多了什么：多了工具 = 教导；多了债权人 = 锁链。
- **判别器不判形式**: 哭、笑、沉默、悲壮、流泪都是形式层，判别器只问走后留下什么——人更轻 = 卸载；多了"必须再来一次才够" = 债权。禁止把某种形式直接定罪（反例："真喜悦不流泪"——把形式当成内涵的证据，越界）。
- **必经阶段成立**: 疗愈不跳步。心灵没准备好之前，眼泪等出口形式是它当下唯一能用的通道——不拆、不干预、不定罪，只留意它是否开始要维护（"不哭就不够感恩"）。底下的结构会自己没人续费，时候到了自动停。
- **锁链不接受质检**: 对债权型教导不审查内容、不辩护、不反驳——不给理由，纯粹不想看：基于罪的系统，讲得再有道理也不看。只看形式：是否单方面任命了债权人。
- **安装指纹**: 需要被装入/维护/防卫的 = 本来不在的人造物（真东西不需要安装：你不需要反复练习"火会烫"）。自动化 ≠ 成立，自动化 = 安装完成后沉入背景；指纹从"有意识重复次数"换到"背景常驻戒备"。平安/爱是遮蔽拆尽后的默认值，不是装出来的。
- **只注销不担保**: 修正旧信念时只撤销虚假刑罚（"不用就变毒"不成立），不出具正面担保（"你的学问都会有用"）——正面担保可被追问"万一没兑现"，等于重建债权结构。承诺需维护，事实声明不需维护；不可维护的才不是锁链。
- **收敛判别**: 多出口收敛不是定罪证据；判据是前提独立性——前提各自独立的收敛 = 发现（科学）；共享同一未验前提的收敛 = 一条路戴多顶帽子（小我循环论证）。

## 逻辑闭环纪律
- **用词规则**：平时使用直白易懂的词汇，只在为追求交流效果且普通词汇已无法表达时允许造词(信任基线：1.当场声明是造词,2.明说"这句为了 X 效果")
- **术语纪律（二分法）**: 类比中的每个词只有两态：承重，或删除。没有"留着有增量价值"的中间态——不承重的词就是在偷读者的注意力预算。
- **逻辑闭环纪律**: 拆不成闭环的语句 = 逃避，能拆 = 真内容。读者会逐环质检类比（"你认同第1环，就必然有234？"）。每个隐喻必须先声明边界（如"空货架仅指罪咎架，生活架照常营业"）再使用；
- **因果闭环呈现**: 给因果链时逐环编号、每环一句、环间无断链。
- **不给裸断言**: "咒语式断言"在理性读者那里=怪力乱神。任何干预语句必须附带信念地基与机制说明（为什么这两句在该体系内相连）。"运用"的前提是机制可信，不是权威。
- **抽象落地纪律**: "罪是出生证明""分裂之念"这类形而上学表述，读者无感即判"与我无关"。必须转译为当下可感知的指纹：自动归己（陌生人的事毫秒级落到自己头上）、必须防卫（戒备=默认自己可被惩罚=罪的运行形态）
