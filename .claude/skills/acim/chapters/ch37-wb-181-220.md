# 练习手册 第181–220课+复习六：强化宽恕，穿越黑暗

## 核心思想
181–200课导言点明任务：这几课"专门为巩固你的愿心而设"，针对"局限你视野的具体障碍"痛下针砭——每天试着放下防卫片刻。201–220课的复习六则以"我不是一具身体，我是自由的"为锤，把最后的身体认同敲碎。

## 本组操练框架
- **181-200课 防卫撤除练习**: 每天只要求一件事——放下防卫片刻。练习中不回顾过去、不操心未来，只着眼于当下心内的无罪本质。一有障碍出现，立即用"这不是我想要看到的"+ 当天中心句改变焦点。
- **191-200课 任务确认**: 每天早晚10-15分钟，确认"我是上主的神圣之子"、"一切事情都是上主要我学习的课程"，把未来交到上主手中。
- **复习六(201-220课)**: 每天只练1个观念，次数愈多愈好；早晚至少15分钟 + 每小时复习 +  hourly之间随时运用。主题句"我不是一具身体。我是自由的。因我仍是上主所创造的我"作为一天开始与结束。杂念出现时："我不想要这种念头。我选择____。"
- **遇诱惑即时句**: 一受诱惑，尽快重申自由，用上面句式立即替换。

## 关键概念
- **焦点转移(181课)**: "知见必有一个着眼的焦点……只要改变这个焦点，你眼前的景象也会随之改变"——不看弟兄的罪，只看无罪本质。
- **信赖弟兄(181课)**: "我信赖我的弟兄，他们与我是同一生命"——信赖是建立自信的关键，攻击弟兄=声明他是那副德行。
- **神圣一刻(193课)**: 救恩来临的一刻——不是未来事件，是当下可经验的时刻。
- **世界救恩操之在我(186课)**: "世界的救恩操之于我"——个人操练与宇宙救赎直接挂钩，无中间层级。

## 心智模型
- 当眼前全是别人的错时→用相机对焦类比：181课=失焦不是因为世界模糊，是对焦点钉在了错误平面(弟兄的罪)上；把焦点移到无罪本质，同一画面立刻清晰。
- 当觉得"念头控制不了我"时→用入侵检测类比：复习六"一注意到杂念，立刻拒而不受"=IDS 规则——不分析 payload，不谈判，直接 drop 并重定向到当天中心句。
- 当纠结身体受限时→用容器类比：201课"我不是一具身体"=你不是 Docker 容器，你是宿主机——容器(身体)的资源限制不是你的限制。

## 常见卡点(反模式)
- **与过去未来纠缠**: 181课点名"成功最大的障碍，就是与过去及未来的目标纠缠不清"——解法：练习中只守当下这一刻。
- **把黑暗当真实**: 181-190课反复处理"障碍好似遮掩无罪本质"——注意课文说障碍"好似"遮掩，不是真的遮掩。
- **追求特殊体验**: 导言说平安可能"断断续续"无妨——追逐高潮体验本身就是障碍。
- **复习六的字面拘泥**: 导言明言"超越表面文字及特定格式"——此阶段重心从形式转向直体验。

## 实修示例
起床：复习六当天观念+主题句，闭眼15分钟。白天遇评判冲动：立即"我不想要这种念头。我选择[当天观念]"。与人冲突：181课焦点转移——默念"这不是我想要看到的。我信赖我的弟兄，他们与我是同一生命"，把焦点从对方的错移到对方的无罪本质。午后：确认"世界的救恩操之于我"，把个人烦恼接入更大框架。睡前：主题句作一天结束，15分钟静默。

## 要点
1. 本组是全程的"压力测试段"——前面建立的平安在181-200课被专门设计的障碍攻击。
2. 唯一要求：每天放下防卫片刻；其余"保证会水到渠成"。
3. 复习六进入极简模式——一个观念足以包含整部课程，前提是运用时不破例。
4. 身体认同(201-220)是旧体系最后一块硬盘，敲碎它即上篇毕业。
