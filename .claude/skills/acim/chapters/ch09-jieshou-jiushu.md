# 第九章 接受救赎

## 核心思想
你怕的从来不是上主的旨意，而是你自己的真相；你的意愿与上主旨意原无二无别，接受救赎就是接受这一事实，平安与救恩因此而变得轻而易举。

## 框架与法则
- **幸福法则**: 上主是爱这一事实不需要你信仰，只需要你接纳；你有否认的本事，却没有改变它的能力。
  - 何时用: 当你想用自己的评判改写现实、感到焦虑沮丧时。
  - 如何用: 停止扭曲真相——扭曲真相只会制造惊惶；单纯接纳"只有真的才可能存在"。
- **给予=接受的互惠法则**: 你给出什么，就会得到什么；得到代表接受而非获取；你必须心甘情愿地给出，才能认出自己拥有的一切。
  - 何时用: 想确认祈祷是否蒙应允、想知道自己拥有什么时。
  - 如何用: 检视自己在每个人身上认出多少圣灵——你献给祂多少，才能从祂那儿求得多少。
- **宽恕是视而不见**: 圣灵所教的宽恕从一开始就无视他人的错误，使错误显得虚幻不实；绝不用恐惧化解恐惧，也不先弄假成真再销毁证据。
  - 何时用: 看到弟兄犯错、想纠正他时。
  - 如何用: 不指出错误（指出错误只可能透过小我看到），只着眼于他是上主之子这一真相；修正是上主的事，不是你的事。

## 关键概念
- **两种评价**: 你心中对自己有圣灵与小我两套矛盾评价，不可能同真；圣灵根据你的真相评价你，小我以反复无常评价你。
- **尚未疗愈的治疗师**: 想给人自己尚未得到之物的治疗师（小我）；他无法修正任何人，唯一贡献是亲身示范方向如何被扭转。
- **庄严伟大 vs 虚夸自大**: 伟大出自上主，只会得到爱的回报、能行奇迹；自大出自小我，是绝望的面具，含有攻击意图，无法共享。
- **定价即定值**: 评判本身就是一种定价；你定了价就得付出代价。
- **基督二度来临**: 不是真相逝而复返，而是你终于觉于真相、恢复清明神智。
- **星星之火**: 被"光明宝相"遮蔽后仅存的创造呼声；认出它带来疗愈，了知光明才有创造能力。

## 心智模型
- **把祈祷看作 API 调用**: 你向圣灵祈求的必蒙应允，但小我的祈求"徒具形式、骨子里是排斥"，等于空请求——发出的请求没有语义，自然收不到对应响应。
- **把修正看作越权写库**: 错误属于小我层，根除小我是上主的权限；你擅自"纠正"弟兄，等于用错误权限写他人数据，连自己那份修正机会也一起丢失。
- **把伟大/自大看作真品与仿冒**: 伟大是硬件原厂规格（上主所造，不可取代，你缺席则天心空位），自大是山寨贴牌——两者极性相同（都虚妄），可以轮番登场；真值只有一个，不会摇摆。
- **把医治看作方向调转**: 指出病人的处境只是读取状态；疗愈是让他亲眼看到"不再相信梦魇者"身上的光明，知见由此转译为真知。

## 反模式
- **向小我要安全感**: 你锲而不舍向不可能让你如愿的老师索求答复，只因害怕自己真的如愿以偿——这给你安全假相，而安全只存在于真相里。
- **先当真再宽恕**: 小我的宽恕策略是先看清错误、再假装视而不见；既已秋毫毕察，便再也无法视而不见，只好求助"神秘"学说。
- **自我贬低的交换**: 用贬低价值的方式换取某物，即使得到也不会珍惜——你给出的定价成了它的身价。
- **为小我的反应辩护**: 小我在"猜忌狐疑"与"心狠手辣"间摆荡、反复无常；以它为向导是彻头彻尾的悲剧。

## 实修示例
弟兄对你出言不逊。小我的路径：指出他的错误并加以"修正"——这只会透过你自己的小我看到错误，等于告诉自己"他是错的、你也是错的"，两人一同错过修正。圣灵的路径：无需口头上认可他的言行，但心里认定"他仍是对的，因为他是上主之子；有待修正之处在另一层次"；把他的错误与自己的错误一并交托圣灵。结果：他的错误与你的错误一并受到宽恕——救赎和爱一样不容分裂。要听到耶稣之声，只有聆听弟兄内在的天音；要确认祈祷蒙应允，先祝福弟兄。

## 要点
1. 你不可能只为自己找到喜悦，也无法仅为自己祈求——圣灵的答复必是针对你与弟兄共享的实相而发。
2. 评判就是定价，定价就得付费；想低买高卖等于相信自己能与上主讨价还价。
3. 你教什么就学到什么——想修正弟兄，就把他的错误与自己的一并献给圣灵。
4. 你的伟大出自上主、不可取代；接受自己的渺小才是傲慢，因为那是拿自己的评价压过天父的评价。
5. 没有我，连上主都无法圆满——记住这句，就不听信小我那一套。
6. 搞错自己的任务是小我最常犯的毛病；圣灵的天职不是你的任务，除非接受这一点，你不知自己的任务。

## 关联
- **第七章**: 神圣关系的具体运用——把弟兄当作认出自己真相的唯一媒介。
- **第十一章**: 两种评价体系（圣灵/小我）直接展开为上主与小我的道路抉择。
- **第十三章**: "救赎不容分裂"的思想为清白无罪的世界奠基。
