# 练习手册 第1–50课：撤销旧知见

## 核心思想
前50课做一件事：拆除"意义在于外在对象"的整个旧架构。从"我所看到的一切不具任何意义"起步，一路拆到"上主的圣爱支撑着我"——知见的地基被清空，只为换上新的。

## 本组操练框架
- **随地取材、一视同仁**: 目光落在何物，何物即练习对象。不刻意加入，绝不故意排除；桌子与钮扣、苍蝇与苹果等价。前3课每天不超过2次、每次约1分钟。
- **由外而内**: 1–3课取材于"所见之物"，第4课起转入"心中念头"——念头像所见事物一样不具意义。第5课起再转入情绪："我绝不是为了我所认定的理由而烦恼"。
- **短、频、轻**: 一天3-4回，每回约1分钟省察心念；轻松自在比彻底更重要，"以免练习沦于仪式化"。
- **固定句式填空**: "____不具任何意义"、"我不是为了我所认定的理由而气/怕/担心____"——用具体名称，不抽象化。

## 关键概念
- **无意义**: 不是虚无主义，而是"意义非对象固有"——意义是我赋予的(第2课)，故可被收回。
- **过去的经验**: 我所见的只是过去(第7课)——知觉是缓存的旧数据，不是实时输入。
- **非中性念头**: 每个念头都带有后果，没有一个念头只是"想想而已"(第16-19课)。
- **神圣本质**: 第35-40课转入建设性陈述："我的心灵是上主天心的一部分，我是非常神圣的"。

## 心智模型
- 当确信"我看到的就是现实"时→用 ML 类比：你看到的全是训练集的历史标签(第7课"我所看到的只是过去的经验")——模型从没见过新数据，只在 replay 旧批次。撤销=清空错误标注，准备重新标注。
- 当觉得"这个想法没什么大不了"时→用电路类比：念头不是中性的导线，第16-17课说每个念头都带电——非中性念头是持续向系统注入偏置电流的隐藏电源。
- 当烦恼想找"原因"时→用调试类比：第5课"我绝不是为了我所认定的理由而烦恼"= stack trace 指向的崩溃行从来不是根因，根因在更深的错误假设层。

## 常见卡点(反模式)
- **区分对象贵贱**: 觉得某些东西"不适合"套无意义——这正是练习要拆除的差别心；解法：目光落哪就练哪。
- **仪式化**: 追求巨细靡遗导致紧张——课文明确说轻松比彻底重要。
- **只挑"坏"念头练**: 第4课警告"好"念头同样是遮蔽真念头的阴影，好坏皆须一视同仁。
- **把"无意义"理解为厌世**: 这是清空字段以便重写的格式化，不是删除硬盘。

## 实修示例
起床：环顾房间一圈，对5件物品默念"X不具任何意义"，约1分钟。通勤：目光落在何物即套用何物，不挑对象。遇烦心事：先写填空"我不是为了我所认定的理由而烦____"，承认烦恼另有根源。睡前：省察今天最强烈的1-2个念头，套用"这个念头不具任何意义"。

## 要点
1. 前50课=格式化旧硬盘：不建新房，只拆旧房。
2. 一视同仁是核心手法，差别待遇即旧知见的复活。
3. 从"所见之物"→"心中念头"→"情绪烦恼"，取材逐步内移。
4. 第35课起开始出现肯定句，拆除与重建已经开始交叠。
