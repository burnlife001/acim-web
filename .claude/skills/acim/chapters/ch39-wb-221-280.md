# 练习手册 下篇第221–280课

## 核心思想
221–280课沿"何谓"定义链展开实修：从"愿我心平安"(221)到"造化的自由保证了我的自由"(280)。操练主线是——撤销定罪(227-229)、忆起天父(231-236)、认出无罪(241-250)、只看基督的慧见(261-280)。身体不再是自我，而是可用可不用工具；世界不再是家园，而是有待宽恕的对象。

## 本组操练框架
- **每课结构**: 当天中心思想 + 欢迎词 + 静默等候；念完 slowly，默想一会儿，再进入神圣时光。
- **即时应用**: 221-230课强调行住坐卧都在上主内——中心句在全天任何场景可用。241课"神圣的一刻"要求今天就给出，非未来某天。
- **选择操练**: 251课"除了真理之外，我一无所需"——每当想要什么，改为想要真理。261-270课训练"不看万物的差异"，遇评判时立即切换。
- **睡前回顾**: 每天结束前确认当天中心思想已融入睡眠，而非仅白天练习。

## 关键概念
- **解脱的神圣一刻(226课)**: 当下即可经验的解脱，不靠时间积累。
- **定罪终结(227-229课)**: "上主从未定我的罪，我也不再定罪"——罪只是错误，非身份。
- **心归我管辖(231课/252课)**: "我的心归我管辖，也只有我管得了它"——注意力的主权回收。
- **无罪无惧(238课)**: "你没有任何恐惧的理由"——恐惧基于罪咎，罪咎既撤，恐惧失根。
- **基督慧见(271课)**: "今天我要发挥基督的慧见"——用祂的眼光取代自己的判断。

## 心智模型
- 当觉得"罪疚是真实的"时→用 git 类比：227课"上主从未定我的罪"=仓库历史里根本没有 commit 过罪——你本地看到的罪记录是未推送的脏工作区，直接 checkout 即可，无需赎罪 PR。
- 当注意力被外界抓走时→用进程调度类比：252课"心归我管辖"=你是 scheduler，不是被抢占的进程——上下文切换的决定权在你，别把 CPU 让给小我进程。
- 当评判眼前人时→用 VR 渲染类比：271课基督慧见=换渲染引擎——同一场景数据，肉眼引擎渲染出威胁，基督引擎渲染出无罪，输入数据没变，着色器换了。

## 常见卡点(反模式)
- **把神圣一刻推到未来**: 226/241课都是"此刻、今天"——拖延=否定其本质。
- **口头无罪、心里定罪**: 227课后若仍对某人怀怨，说明操练停在字面——检查是否真把"罪=错误"当了实底。
- **用肉眼找平安**: 261-270课连续十课拆"肉眼之见"——用肉眼找平安如用温度计测长度。
- **只在座上练**: 221-230课明确"行住坐卧都在祂内"——座上座下无分界线。

## 实修示例
起床：当天中心思想+欢迎词，静坐等候片刻。通勤：252课"我的心归我管辖"，把每个注意力的漂移收回来。遇冲突：先271课——"我要发挥基督的慧见"，想象用祂的眼光看对方，再回应。午后：251课检查欲望——"除了真理之外，我一无所需"，把当下想要的任何东西换成真理。睡前：226课"这是我解脱的神圣一刻"，带着这个入睡。

## 要点
1. 本组把"何谓"的定义落到操作：无罪(227)→管辖心(252)→基督慧见(271)是操作化三步。
2. 定罪终结是本组枢纽——上主不定罪，你也不必；不定罪则恐惧无理由(238)。
3. 肉眼之见被系统降级：从"信息源"降级为"待修正的原始数据"。
4.  freedom 主题(280课"造化的自由保证了我的自由")收束：你给自己的限制≠造化给你的限制。
