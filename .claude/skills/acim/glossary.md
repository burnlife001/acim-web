# ACIM 术语表(教师指南 + 词汇解释)

**基督(Christ)** — 上主的完美之子、唯一造化,永远肖似上主且一体不分 (词汇1, 5)

**基督圣容** — 宽恕最醒目的象征,真实世界的象征;一见此容,你已被宽恕 (词汇3)

**复活** — 克服/超越死亡,心灵改变了对世界的看法;宣告学习阶段功成身退 (指南28)

**怪力乱神(magic)** — 企图取代上主旨意、把幻相弄假成真的伎俩;扎根于牺牲与分裂,毫无意义故极易摆脱 (指南9, 16, 17)

**慧见** — 基督的慧眼,越过一切错误直指内在的基督 (词汇2)

**救赎(Atonement)** — 上主圣言;接受救赎=获得疗愈=宽恕;无程度之别,故奇迹无难易之分 (指南22)

**救恩性的宽恕** — 唯一真宽恕:不求代价、不评判、口心一致;"我该为这位圣子作些什么?" (颂祷2)

**上主** — 纯爱;天心=上主之心;从不定人之罪,其审判纯粹出于爱 (指南19, 20)

**上主的天音** — 圣灵之声;上之师的唯一向导 (指南16, 21)

**上主之子** — 永远清白无罪;了悟他无罪即结束死亡 (指南27)

**上主的平安** — 彻底明白上主旨意不可能有对立;宽恕所在之处,平安必来临 (指南20)

**上主之师** — 唯一资格:视他人福祉为己福祉;任务是帮人节省时间 (指南1)

**心理治疗** — 唯一真正的治疗,因为只有心会生病;本质即宽恕的过程,医患互为救主 (心理治疗)

**神圣关系** — 共同学习目标圣化关系,圣灵必进入其中 (指南2)

**神圣会晤** — 弟兄萍水相逢、彼此祝福、同领平安;最理想治疗的组成单位 (治疗2)

**神圣助手** — 上主为把幻境当真的圣子造的领路者,祭坛上原是同一个;对你,耶稣是唯一必需者 (词汇5)

**信赖** — 上之师思想体系的根;形成六阶段:化解→厘清→舍弃→安顿→动荡→完成 (指南4)

**决定权交托** — 把决定权还给圣灵=由恐惧脱身;养成"凡事问,随时问"的习惯 (指南29)

**轮回** — 究竟来说不存在(无过去未来);只按"对人有无益处"处理,不采取立场 (指南24)

**教与学** — 教就是学,互为师生;你无时无刻不在以身作则,没有不教的自由 (指南导言)

**宽恕** — 带你接近上主但不出自上主;存在世界之内却直通天堂彼岸的桥梁 (词汇3)

**正见** — 聆听圣灵之音的知见;宽恕、救恩、救赎、正见全是一回事;是最后一个知见 (词汇4)

**真祈祷** — 无所求、宁静聆听、奉献合一;主题曲是感恩与爱的颂歌,具体答复只是回音 (颂祷1)

**真知** — 上主不变、肯定、纯净之境;知见无法企及 (词汇1, 4)

**牺牲** — 相信幻相必付的代价;上主从不索求牺牲,放弃牺牲观才发现一切原是恩赐 (指南13)

**身体** — 用途的镜像:用于交流则圣化,用于攻击则定罪;用途尽时可平静弃置 (指南12)

**圣灵** — 代上主发言的天音;内有真知又具世间知见,是唯一天人管道;住在你心内基督之心部分 (词汇6)

**十项特质** — 信赖、真诚、包容、温良、喜乐、不设防、慷慨、耐心、忠信、开放的心 (指南4)

**耶稣** — 在所有弟兄身上看到基督圣容而忆起上主的人;圣灵立他为实现救赎计划的领袖;呼其名=感谢上主一切恩赐 (指南23; 词汇5)

**小我** — 你对自己真相所作的梦;不可正面界定,凡与其相反者即是奇迹:"奇迹宽恕人,小我诅咒人" (词汇2)

**通灵能力** — 无超自然力;是撤除心灵自设的限制,献给圣灵则有用,据为私有则致命 (指南25)

**假疗愈 vs 真疗愈** — 以幻相换"较好"幻相、只治身体 vs 全面疗愈、病因为除、死亡化为平安解脱 (颂祷3)

**三层心境** — 一体心境(基督心)、正见心境、妄见心境;正见仍属知见,不是真知 (词汇1)

**最后审判** — 宣判"你是圣洁、永恒、自由而且圆满无缺的";在你不再怕它时才来临 (指南15)

**罪咎** — 幻相;教病患看出它既非真实又不足取,疗愈便完成 (治疗2)

**最后的一步** — 由正见到真知的跨越,由你转交给上主完成 (词汇3)

**毁灭性的宽恕** — 揪出并放大对方的罪;化身:屈尊俯就、同病相怜、殉道者、讨价还价 (颂祷2)

**分裂取向的疗愈** — 凡含"你我不平等"心态皆是假疗愈 (颂祷3)

**死亡的真相** — 一切幻相的核心梦境,象征"上主可畏";上之师不接受任何带死亡阴影的妥协 (指南27)

**不设防** — 防卫保护的是疯狂幻相;放下后随之而来的是安全感、平安、喜乐 (指南4, 16)

**与上主直接相通** — 原无隔阂,需先清除障碍;可遇不可求,不作可行目标;已证入者为"众师之圣师" (指南26)

**尚未疗愈的治疗师** — 视病患为威胁、自负成败;角色混淆是一切限制之源 (治疗2)

**真谦逊** — 除上主外无其他目标;其"无我"即"真我";阶梯尽头的门槛 (颂祷1)

**敌人** — 陷于囹圄的基督,其实是你自己;释放他=释放自己 (颂祷1)

**付费法则** — 疗愈无价;所需金钱自会来,那不是酬金;无人因付不起费用被拒门外 (治疗3)

**判断的放弃** — 不是不应该判断,而是无法判断;唯一真判断经由你:"上主之子是清白的" (指南10)

**正义** — 针对不义的修正;上主的审判接受全部证物,绝不孤立个人 (指南19)

**教学三层次** — 刹那邂逅、一段时期的高峰经验、终生关系;救恩中没有偶然 (指南3)

**世界太平** — 不是世界使平安无法立足,而是你眼中的世界不允许平安存在 (指南11)

**世界的结束** — 在全面彻底的宽恕中,罪咎失去目的而销声匿迹;不遭毁灭,只是失去虚幻存在 (指南14)

**真死亡** — 自愿抛弃外衣的平安解脱,是赏报而非惩罚;假疗愈仍以冷酷死亡炫耀胜利 (颂祷3)

**十项特质的次序** — 信赖为根,真诚、包容、温良、喜乐、不设防、慷慨、耐心、忠信、开放的心依次而立 (指南4)

**疗愈工作者** — 认出自己与求助者同一生命的人;不为自己说话,只代圣灵发言 (颂祷3)

**选择病患** — 上门的每一位都是你的病患;谁需要什么是他内的"一物"告知的,聆听,不自作主张 (治疗3)

**小我两大基本错误** — "发怒能帮我达到目的"+"攻击保护自己理直气壮";化解之深=得救之深 (治疗2)

**攻击─防卫循环** — 心理治疗核心难题;治疗师以不还击回应攻击,示范不设防即力量 (治疗2)

**病征替换** — 基督进入关系后,平安与疗愈成了关系的"症状",取代先前所有病征 (治疗2)

**身体不可能真正被治愈** — 身体治疗只是苟延残喘;认清身体是什么,谁还会想生病 (颂祷3)

**疗愈的定义** — 宽恕的过程;不宽恕者即病人,紧抓罪咎当护身符 (颂祷3)

**结语** — 结局已定,上主亲自作保;天堂就在当下此地,心终于平安 (词汇结语)
