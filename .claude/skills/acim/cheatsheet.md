# 奇迹课程 · 速查决策表

## 总纲(全书一句话)
凡是真实的, 不受任何威胁; 凡是不真实的, 根本不存在。上主的平安即在其中。

## 快速诊断决策树

**此刻烦扰不安?**
→ 烦扰 = 练习信号。不是外境出错, 是诠释出错。
- 自问: "我把什么当真了?" → 凡是会受伤、会失去、受威胁的, 都不是真实的。
- 执行宽恕: 收回投射 → 交出评判 → 邀请圣灵 → 看见清白。

**该听谁的?(顾问选择)**
| 信号 | 小我(错误顾问) | 圣灵(正确顾问) |
|---|---|---|
| 语气 | 急促、定罪、特殊性 | 平安、一体、无例外 |
| 焦点 | 过去恩怨/未来恐惧 | 当下这一刻 |
| 结果 | 分裂感、防卫 | 延伸、疗愈 |
| 规则 | 平安为试金石: 不安 = 问错了顾问, 重选 |

**面对攻击?**
→ 重新诠释: 攻击 = 爱的求助 → 回应求助, 不定罪。

**做不到宽恕?**
→ 降级到"小小的愿心": 只需愿意。利用抗拒本身练习。不要求相信, 只要求运用。

## 关键阈值与默认规则
- **零例外**: 一个例外 = 全盘失效。例外感 = 最需要练习处的标记。
- **平安试金石**: 任何决定/诠释带来不安 → 判为小我, 撤销重选。
- **难易无别**: 大问题与小问题是同一个错误; 别给问题分级。
- **一天一课**: 勿贪多; 操练靠重复与普遍化, 不靠速度。
- **目的何在**: 唯一测验。对任何关系/物品/计划, 问"它的目的(给我的)是什么"。
- **无需牺牲**: 凡让你觉得自己在"付出牺牲"的给予 = 小我的交易, 非推恩。

## 危险信号 (Tells & Smells)
- 感到特殊(被亏待/被偏爱) → 特殊性 = 爱的替代品, 恨的避风港。
- 想证明对方有错 → 定罪他人 = 自我定罪。
- "等这件事解决了我就平安" → 平安是先决条件, 不是结果。
- 用课程术语指责他人 → 灵修 bypass, 教成了定罪工具。
- 为过去解释现在 → 把果当因; 当下不需要任何过去背书。

## 两组根本对立(真值表)
| 幻相系统(小我) | 实相系统(圣灵) |
|---|---|
| 分裂、死亡、罪咎 | 一体、生命、清白 |
| 知见(perception) | 真知(knowledge) |
| 索取/交易 | 给予/推恩(给即是得) |
| 特殊性 | 神圣关系 |
| 审判 | 宽恕 |
| 身体为自我 | 身体为交流工具 |

## 用技术类比速记
- 小我 = 有 bug 的 legacy 代码, 运行在"分裂"的错误假设上; 不可修复, 只能整体弃用(undo)。
- 圣灵 = 内置的正确解释器/编译器, 一直在后台, 等待被调用(邀请)。
- 宽恕 = git revert 错误提交 + 拒绝再 cherry-pick 旧恩怨。
- 练习手册上篇 = 清空错误权重; 下篇 = 用正知见重新训练(直接体验)。
- 神圣一刻 = 中断当前进程, 以零历史状态重启感知。
- 奇迹 = 知见层面的热切换(failover): 恐惧通道 → 爱的通道, 无难易之分。
- 电路类比: 恐惧是断路(自以为与源头断开), 奇迹是恢复通路; 电流(爱)从未停止, 断的只是你的接入感。
