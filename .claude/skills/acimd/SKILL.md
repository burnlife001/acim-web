# acimd：对话灵感存档

把（通常是和 hermes 的）杂乱对话整理成书集文章，写入（路径均为仓库内相对路径，Windows/WSL 通用）：
- **日记** `src/books/07.日记/` — 感悟、灵感、杂记、非问答式内容
- **问答** `src/books/06.问答/` — 一问一答，正文含 `## 问：` 结构

## 流程（一轮完成）

用户说出存档意图后，**直接执行**步骤 1–4，不用先出草稿等确认。

### 1. 定目录
看内容形态：有明确"问：…答：…"结构 → wenda；其余 → riji。拿不准就问用户。

### 2. 提炼标题和正文
- **标题：意义优先，不是主题优先**。标题取自正文的**核心结论/洞察/金句**，让读者只看标题就知道"这篇主张什么"，而不是"这篇关于什么"
  - ✅ 好标题（观点/结论）：「要开心还是要宽恕」「不顾你死活的向爱求助」「无存量服务协议」「懂与不懂谁更合适」
  - ❌ 坏标题（话题/情绪/氛围词）：「悲壮」「阴天」「关于宽恕的思考」
  - 提炼顺序：**先写正文 → 从正文里找结论句或最有力的那句 → 压缩成标题**。找不到结论句说明正文还没提炼到位，回去改正文
  - 用户自己给标题时，用户版本优先，直接采用
  - 硬性约束：不含日期、不含序号、不含非法字符（`\/:*?"<>|`）
- **正文**：markdown。整理而非照搬——去寒暄、合并重复、保留金句和判别器式结论。问答体用 `## 问：xxx` 分节（参考 011.药物与符咒.md）
- 日记正文一级标题可用 `# 标题：副题` 形式（参考 2026-10-02-03）

### 3. 生成文件名（必须用脚本，不要自己编文件名）
从仓库根执行（Windows 用 `python`，WSL 用 `python3`；脚本自动按自身位置定位仓库，与系统无关）：
```bash
python .claude/skills/acimd/scripts/gen_filename.py riji "标题" --full
python .claude/skills/acimd/scripts/gen_filename.py wenda "标题" --full
```
输出即目标绝对路径。规则：
- 日记：`YYYY-MM-DD（标题）.md`；当天已有文件则 `-NN` 递增（当天首个无后缀文件视为 01）
- 问答：`NNN.标题.md`，取现有最大序号+1

注意：脚本给出带后缀文件名且当天存在无后缀旧文件时，脚本已自动把旧文件改名为 `-01`（stderr 有提示，`-01` 已存在则跳过并告警）。无需再问用户，回显路径时顺带说明改名结果即可。

### 4. 写入并回显
用 Write 写入脚本输出的路径，然后回显写入路径，并提醒：需要发布时跑构建/提交。

**不要**手动更新两个目录下的 `index.md`——`scripts/build.mjs`（gen-index.mjs）会自动重建目录和搜索索引。

## 禁区
- 禁止自己拼文件名（日期错误、序号冲突都出过）
- 禁止改动其他已有文件（唯一例外：脚本对当天无后缀日记的自动 `-01` 改名，见步骤 3）
