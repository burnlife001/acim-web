# 架构

## 项目性质

零构建纯静态 PWA。`src/` 即发布根，单 `index.html` 运行时 fetch Markdown，iPhone Safari 优先。无服务端、无鉴权、无数据库——Cloudflare Pages Functions/D1 迁移已回退（functions/、migrations/、wrangler.toml 已删除）。

## 常用命令

```bash
bun scripts/build.mjs              # 改.md 后仅更新 tmp/search.json, 增删.md 后更新index.md ,tmp/search.json、tmp/filelist.json，  
bun scripts/serve.mjs [port]       # 预览，默认 4173，从 src/ 起
bun scripts/e2e-m1.mjs             # E2E + 截图（m1=基础 m2=搜索 m3=今日课 m4=PWA）
bun scripts/e2e-search-reenter.mjs # 回归：文档页再搜索点当前文档结果须关搜索层
bun scripts/deploy-skill-dsh.mjs   # 把 .claude/skills/acim 部署到 deepseek harness skill 根
```

E2E 依赖 `puppeteer-core` + 本机 Chrome（路径见 `scripts/e2e-m3.mjs` 硬编码）；截图存 `e2e-out/`。无单元测试框架。

## 架构

**入口**：`src/index.html` 内联全部视图逻辑（hash 路由 + marked 渲染 + MiniSearch 调用）。所有源码都在这一个文件里，没有 JS 模块拆分。

**启动**：并行拉 `books/cfg.json`（站点/课表/日历契约）与 `tmp/books.json`（书集清单 = `src/books/` 子目录名数组，gen-index 产物），均 `no-store`。两者是前端首取依赖，SW 必须预缓存。

**路由**：`#/{book}` 看书首页、`#/{book}/{path}` 看正文（path 相对书根，正斜杠，hash 经百分号编码、`decodeHash()` 统一解码）。`book` 为书集目录名（如 `01.正文`、`02.练习手册` … `07.日记`），合法性以 tmp/books.json 为准。顶栏 ↑ 回上级（正文页→书目录→全部书籍）。

**内容**：`src/books/01.正文`、`02.练习手册`、`03.教师指南`、`04.词汇解释`、`05.补编：心理治疗目的、过程与行业`、`06.问答`、`07.日记`。**每本书的 `index.md` 是构建产物**（`gen-index.mjs` 重写），既是人读目录页，也是阅读器侧边栏/搜索的实时数据源——勿手改，改了也会被覆盖。文件名（含子目录结构）即显示标题与导航路径。

**配置**：`src/books/cfg.json` 是唯一配置入口，三段：`site`（标题/subtitle/storagePrefix/uidDomain）、`lessonBook`（课表书集契约：book/filePattern/range/mergedFile/mergedRange/firstLesson）、`calendar`（ics.csv 契约、文件名与标题模板、defaultTimes、prodid）。`lessonBook`/`calendar` 可空，空了对应功能自动关闭。gen-index.mjs 按它做课表/日历校验。

**数据文件**：`src/books/ics.csv`（课号→时刻表，两列 `lesson,times`，365 行，日历提醒数据源；日历标题运行时从课文件名/361-365.md 首个 H1 解析）；`src/tmp/{books,search,filelist}.json`（构建产物，gitignore）。

**vendor**：`src/vendor/{marked.min.js, minisearch.min.js}` —— 唯一两个外部库，本地化、不走 CDN。

**搜索**：MiniSearch 索引 tmp/search.json（约 2.7MB，首次打开搜索层才加载）；CJK 单字+二字组分词，AND 组合 + 原样包含二次过滤（剔除 bigram 假阳性）；结果指向当前 hash 时手动补一次路由（hashchange 不触发）。

**PWA**：`manifest.webmanifest` + `sw.js`（`src/` 内）。SW `install` 阶段预缓存 SHELL（含 tmp/books.json、tmp/search.json）+ `tmp/filelist.json` 列出的全部内容文件（50 个/批，逐段 encodeURI）；`fetch` 走网络优先、离线回退、同源 GET 成功即写缓存。版本号常量 `VER`（如 `acim-v17`），改了缓存要 bump。SW 注册在顶层同步代码里，不进 init（await cfg 时 load 事件可能已过）。

**localStorage 契约**：
- `acim:pos:<book>` —— 每本书的上次阅读位置（path）；其中 `acim:pos:02.练习手册` 兼作练习进度：当前课 = 其指向的课号，"导入为今天/明天日历"均放当前课内容，仅落到的日期不同
- 启动时有一次性迁移 shim：旧英文 key（text/workbook/manual/clarification/05.补编）的续读位置搬到中文目录名 key，搬完删旧 key

**每日提醒**：客户端 JS 拼装 `.ics` 文件触发下载（课号走 ics.csv 时刻表；非课号阅读目标用 `calendar.defaultTimes`）。事件标题统一加 `acim-` 前缀——iOS 快捷指令按"标题包含 acim-"批量移除。无服务端、无 webcal、无 Web Push。删除日历事件网页无路（已实测 iOS 导入预览无视 METHOD:CANCEL，只加不删），批量删除由用户自建的 iOS 快捷指令承担，勿再在网页端加删除功能。

## 部署

GitHub Pages，`.github/workflows/deploy-pages.yml`：push 到 main 时按变更类型决定是否部署（网站代码任意变更、或 src/ 下有文件增删 → 部署；仅改已有 md 内容 → 不触发，可手动 workflow_dispatch）。构建 = `bun scripts/build.mjs`，artifact = `./src`。`src/` 不需要拷贝步骤——它就是发布根。

## 构建/脚本约定

- 脚本 shebang `#!/usr/bin/env bun`，本机必须装 bun
- `package.json` 只声明 `puppeteer-core` 一个 devDep
- 课表契约：`books/02.练习手册/` 必须有 360 个 `NNN.` 课号文件 + `03.下篇/15.最后的几课/361-365.md`；`books/ics.csv` 必须恰 365 数据行；`gen-index.mjs` 校验失败则报错
