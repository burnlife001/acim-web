# 307. 我不要那些自相矛盾的愿望

  W-307.1.
天父，祢的旨意，其实就是我的意愿，也是我唯一的意愿。2 我无需其他的意愿。3 愿我不再企图自创其他的愿心，因那毫无意义，只会为我带来痛苦。4 只有祢的旨意才能给我幸福，也只有祢的旨意真实不虚。5 如果我愿拥有唯祢才能给出的礼物，我必须先接受祢对我的旨意，进入那永远不可能冲突的平安之境；在那儿，祢的圣子与祢在本质及意志上都是一体的，我仍是祢所创造的我，世上无一物能与这神圣的真理相抵触。

  W-307.2. 我们怀着这一祷词，默默进入一个冲突无法侵扰之地，因为我们的神圣意愿已经与上主的旨意结合为一，我们也认清了它们原是同一旨意。
