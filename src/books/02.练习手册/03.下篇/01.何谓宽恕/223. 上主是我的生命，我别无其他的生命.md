# 223. 上主是我的生命，我别无其他的生命

  W-223.1. 以前我误以为自己活在祂之外，是另一个生命，在此孤军奋斗，有如一具游魂寄居于身体内。2 如今，我已知道，我的生命就是上主的生命，我没有其他的家，也不活在祂之外。3 祂的每一个圣念都在我内，而我内没有一物不是来自于祂。

  W-223.2.
我们的天父，让我们看到基督的圣容，而非我们的过错。2 因我们是祢的神圣之子，清白无罪。3 我们愿着眼于自己的无罪本质，因心怀愧疚等于宣告我们不是祢的圣子。4 我们再也不愿遗忘祢了。5 我们在此感到孤单，渴望天堂的家乡。6 今天，我们愿意回家了。7 我们的圣名即是祢的圣名，我们承认自己是祢的圣子。
