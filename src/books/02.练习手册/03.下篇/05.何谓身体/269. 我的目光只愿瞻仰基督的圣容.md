# 269. 我的目光只愿瞻仰基督的圣容

  W-269.1.
我今天只祈求祢祝福我的目光。2 祢选择了这一途径，指出我的错误，且引领我超越过去。3 祢赐给了我一位神圣向导，帮我找到新的知见，透过祂的课程，领我超越知见而回归真理之境。4 请赐给我那个幻相吧！它超越我所营造的一切幻相之上。5 今天，我决心着眼于一个被宽恕的世界；世上每个人都显示给我基督的圣容，并教我看出，不论我看到什么，都是我自己的一部分；而且除了祢的神圣之子以外，没有其他的生命存在。

  W-269.2. 今天，我们的目光确实受到了祝福。2 祂的自性即是我们的自性；只要瞻仰到祂的圣容，表示我们享有同一慧见。3 因为祂是上主之子，因为祂是我们的本来面目，我们才能成为一个生命。
