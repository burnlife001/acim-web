# 264. 上主的爱环绕着我

  W-264.1.
天父，不论我在何处，不论我往何方，祢都在我身边，寸步不离。2 祢在我所见到的万物之内，在我所听到的一切声音里，在向我伸出的每一只手中。3 时间消失于祢内，空间变成毫无意义的概念。4 因为圣爱亲自护守在圣子的身边，确保他的安全。5 除了此爱，他没有其他的生命根源，没有一物不分享它的神圣本质，没有一物凌驾于祢的唯一造化，也没有一物不蕴含那结合万物的圣爱。6 天父，祢的圣子肖似于祢。7 今天，我们要因祢之名前来，安心活在祢永恒的圣爱内。

  W-264.2. 我的弟兄，今天就与我合一吧！2 这是救恩的祷词。3 我们岂能推却拯救世界及自己的救恩大业？
