# 275. 今天，上主的疗愈之音保全了万物

  W-275.1. 今天，愿我们静静聆听上主的天音，祂为我们讲述那古老的课程，其真实性不增亦不减。2 然而，今天却是我们寻找、聆听、学习及了解它的特定日子。3 与我一起聆听吧！4 因上主天音所传述之事，我们不可能单独领会，也无法各自分头学习。5 正因如此，万物得以保全。6 正因如此，上主的疗愈之音遍传人间。

  W-275.2.
今天，祢的疗愈之音保全了万物，为此，我将一切交托于祢手中。2 我无需为任何事情操心挂虑。3 祢的天音自会明示我该做什么，该去哪里，该向谁说，该说什么，该作何想，带给世界什么讯息。4 我带给世界的只是天赐于我的安全保障。5 天父，祢的天音透过我而保全了万物。
