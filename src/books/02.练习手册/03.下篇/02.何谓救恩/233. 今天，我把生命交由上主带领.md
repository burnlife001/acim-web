# 233. 今天，我把生命交由上主带领

  W-233.1.
天父，今天我把所有的念头都交托给祢。2 我宁愿没有自己的想法。3 请赐下祢的圣念，取代我的想法吧！4 我要把今天的所作所为交托到祢手中，使我得以奉行祢的旨意，不再追逐那不可能达成的目标，把大好光阴浪费在无谓的幻想里。5 今天，我来到祢跟前。6 我愿退后一步，紧随祢的身后。7 请祢作我的向导，我愿作祢的门徒，不再怀疑祢无限的智慧及圣爱，虽然祢的慈爱超过我的理解，却是祢给我的最完美的礼物。

  W-233.2. 今天，有一位神圣向导引领我们前进。2 我们在同行之际，毫不保留地把这一天交托给祂。3 今天是祂的日子。4 对我们则是充满仁慈与无限恩赐的日子。
