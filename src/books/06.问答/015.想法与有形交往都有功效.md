# T-4.II.2.4 你必须明白，心灵层次的互动，和形体上的交往一样，都会带来这种改变。5 你对另一个小我作何想法，与有形的交往一样，都有改变你们对彼此看法的功效。6 没有比这更能证明“小我只是一个观念，而非实体”的实例了。

# T-4.II.4.7 问题不在于你应怎样对待小我，而在于你相信自己究竟是什么。8 相信，属于小我的功能，只要你对自己的起源还得依靠信念来支撑，表示你仍陷于小我的认知里。9 当你完成学习阶段之后，你只是纯然地“知道”上主。

# T-4.II.8.4 小我就是人心中认定“自己是完全独立自主”的那个信念。5 小我虽然锲而不舍地争取灵性的认可，以肯定自己的存在，却始终无法得逞。6 灵性在真知内不可能意识到小我的存在。7 它也不会攻击小我，因为小我对它而言，纯然“不可思议”。8 小我也一样意识不到灵性，只会感受到有个比它更大的东西始终在否定它的存在。9 由此可知，小我心目中的“自尊”只是一种自欺而已。10 上主的造化是不会创造神话故事的，可是创造的能力却可能误用到神话故事里。11 结果只有一种可能，即是那些妄造出来之物从此丧失了创造力。12 神话纯粹属于知见层次，形式上显得玄玄虚虚，本质上更摆脱不了善恶对立，因此，即使从它们最好的一面来讲，也不免包藏祸心。

# T-4.II.9.5 一群比较“富有宗教情操”的小我，则相信灵魂存在于身体之先，而且是永续的存在，只是一时落入小我的世界里而已。6 有些人甚至相信灵魂将会因这一沦落而遭受天谴。7 其实，救恩对灵性一无所用，因为灵性始终安然无恙，不待任何拯救。

# T-4.III.4.5 你一边把分裂的决定归咎于小我，一边又对亲手打造出来的小我恋恋不舍，内心势必充满冲突。6 人间没有一种爱不是爱恨交织的，世上也没有一个小我尝过毫无冲突的爱，那对它简直是不可思议。7 只要心灵真正想要爱，爱必会出现眼前，但它不能三心两意。8 换句话说，这渴望不能夹杂爱恨交织的情绪，毫不受制于小我想要“取得的本能驱力”。

# T-4.V.2. 构成小我处境失衡的主因，在于它无法分辨身体与上主圣念之间的差异。2 小我无法接受上主的圣念，因为它公然指出小我不存在这一事实。3 因此，小我不是加以扭曲，便是全力抵制。4 但它消灭不了上主的圣念。5 为此，小我只好改用隐藏策略，不只藏起它“难以认同”的身体本能，连上主的圣念也一起打入了冷宫，因为两者对小我构成了同等的威胁。6 小我为了自身的存亡，不能不把两者都视为同一威胁。7 唯有把它们打为一丘之貉，小我才能不受其害；否则，真知一旦现前，小我便无立足之地了。
