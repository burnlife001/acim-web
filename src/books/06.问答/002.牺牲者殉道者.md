# 问
```
  关于殉道者：
  T-9.I.8. 没有一个正见之心会相信自己的意愿比上主旨意的力道更强。2 心灵若相信自己的意愿不同于上主的旨意，只可能导致两种结论：一是相信上主根本不存在，二则认为上主的旨意无比可怕。3 前者会发展为无神论者，后者则会产生殉道者，
  
  那么到底什么才是上主的旨意？
  小我的旨意不是上主旨意，而我活脱脱就是这个小我，直到有一天我能达到天人相通，那时候才算不是小我，
  而身体在这个世界就是存在的，小我就活在身体中，
  直到身体灭亡，才算回归上主，
  那么就是说，我死了才可能知道上主的旨意。
```

**上主的旨意就是你此刻真心想要的平安 —— 不要求你牺牲任何东西。**
