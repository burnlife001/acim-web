# 问：
任何的难受，痛苦，牺牲... 都可以称之为死亡，有印象吧，我想干掉这些

---

有。出处是练习手册第163课："死亡只是一念，却有许多化身"——悲哀、恐惧、愤怒、嫉妒、牺牲，全是同一个念头的变装。
你用攻击去消灭死亡，等于向死亡效忠——因为攻击本身就是死亡。这是递归死循环。

感觉出现时，只看："我此刻选择了恐惧这个诠释"。——这就是全部注视。之后瓦解自动发生，不用你做后续。
注意：评判=追加投资，等于又把它推回黑暗
每次冒出来，都是一次练习机会。



# 问：

不评判=要求无先验，但人类不可能没有先验，这就是个伪命题

---

**前提错了：注视不要求"无先验"，只要求"不再把先验当事实"。**

你不可能清空先验——课程从没这么要求过。要清的不是先验本身，而是**先验对现实的署名权**。
ML 类比精确版：不是删权重（无先验 = 删库，做不到也不是目标），而是**切断梯度回流**——先验照常激活、照常产生输出，
但你不给它 ground truth 的地位，不拿它当 label 去反向传播、加固自己。
权重还在，但它从"训练目标"降级为"待观察的中间产物"。
所以：
- 评判 = 把这个输出认成 label → 梯度回流 → 追加投资
- 不评判 = 看着这个输出说"这是模型的预测，不是数据本身" → 零回流 → 权重自然衰减

你不需要先验为零才开始。你带着满脑先验就可以注视——**把先验本身也变成被注视的对象**。
这就是"小小的愿心"的全部含义：不是"愿意相信课程"，只是"愿意怀疑自己目前的解释可能是错的"。
一粒怀疑，就是断点。圣灵完成其余——梯度不归你算。
