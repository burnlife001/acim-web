# W-21.4 我愿意以不同的眼光去看____（人名）

W-21.原名：我决心以不同的眼光去看

决心：越俎代庖，去做圣灵的工作
愿意：小小的愿心

我愿意以不同的眼光去看父母(他们是梦境中的上主之子)
我愿意以不同的眼光去看父母的辛苦和牺牲(这是因为辛苦和牺牲在我这里还有同样的价值)
我愿意以不同的眼光去看父母的冲突(看到自己的解释,注意到即已提交。)

## [赚钱 = 辛苦和牺牲]从何而来

分裂之念 -> 断网 -> 失去创造力 -> "有"只能靠"拿" -> 交换律 -> 得到必须付出 -> 赚钱=辛苦牺牲
回归一体 -> 联网 -> 创造力回归 -> 圆满 -> 无罪咎 -> 推恩律 -> 给即是得 -> 赚钱=溢出 -> 轻松才是常态

## 两个链条

| 断网链       | 联网链        |
| --------- | ---------- |
| 分裂之念      | 回归一体       |
| 失去创造力     | 创造力回归      |
| 靠"拿"         | 靠"溢"       |
| 罪咎 → 交换律  | 无罪咎 → 推恩律  |
| 得到必须付出    | 给即是得       |
| 赚钱=辛苦牺牲   | 赚钱=溢出      |
| 累是常态，说轻松心虚 | 轻松是常态，累是错链信号 |

注意：
[真给]：给完就忘了，人家不领情你也无所谓，那才是真给。
[免费和收费]：凡是能复制的，免费；凡是消耗你此刻生命的，收费。
[轻松 ≠ 躺平]流通（越干越旺，因为给=得）
[换链不换景]不用搬家，不用辞职，换的是链，不是场景。
[禁止外用]只对自己使用，对别人用可能是`嘲笑`的代名词
